Confidentialité

Dernière mise à jour : 7 octobre 2026

En bref : pas de compte obligatoire, peu de données. Mesure d’audience limitée, préférences stockées dans votre navigateur.

Responsable

JeuxStash — contact : contact@jeuxstash.fr.

Données que nous ne demandons pas

Vous n’avez pas besoin de créer de compte pour utiliser le site. Nous ne demandons pas de nom, adresse, ni moyen de paiement. Les achats se font chez les marchands (Instant Gaming, Amazon, etc.).

Stockage local (votre navigateur)

Certaines préférences restent sur votre appareil via localStorage, par exemple :

  • thème clair / sombre ;
  • liste « Mes jeux » (favoris) — uniquement dans votre navigateur, non envoyée à nos serveurs.

Vous pouvez les effacer en vidant les données du site dans les réglages du navigateur.

Mesure d’audience

Le site peut utiliser des outils d’analytics (par ex. Google Analytics / Cloudflare Insights) pour comprendre les pages consultées de façon agrégée. Ces outils peuvent déposer des cookies ou identifiants techniques.

Vous pouvez limiter le suivi via les réglages de votre navigateur, une extension anti-traceurs, ou le mode privé.

Liens externes et affiliation

Quand vous cliquez vers Instant Gaming, Amazon ou un autre site, leurs propres politiques de confidentialité s’appliquent. Les liens affiliés peuvent permettre au marchand de savoir que la visite vient de JeuxStash.

Vos droits

Pour toute question relative à vos données, contactez contact@jeuxstash.fr. Selon votre situation, vous pouvez demander un accès, une rectification ou une suppression des données que nous traiterions éventuellement.
